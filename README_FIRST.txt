VIMAX.PURE ESP32-S3 N16R8 v0.3 — RECTIFICATION ONLY

Этот архив содержит исправленный проект PlatformIO.
Он основан на версии, которая у пользователя уже собралась с SUCCESS.

Что делать:
1. Открыть папку в VS Code + PlatformIO.
2. Проверить GPIO в include/BoardConfig.h.
3. Нажать Build.
4. Не подключать сетевую нагрузку при первом тесте.
5. Выполнить Upload.
6. Выполнить Upload Filesystem Image (uploadfs).
7. Подключиться к Wi-Fi VIMAX-PURE, пароль vimaxpure.
8. Открыть 192.168.4.1.

Важно:
- Силовая часть после старта отключена (DISARMED).
- Реально активен только процесс 109 — ректификация.
- Остальные режимы являются безопасными заглушками.
- Назначение DS18B20 пока по индексу, перед эксплуатацией нужна привязка по ROM.
- Коэффициенты датчиков давления и тока являются предварительными.
- Управление нагревом сейчас пакетное, рассчитано на SSR/внешний силовой драйвер.
