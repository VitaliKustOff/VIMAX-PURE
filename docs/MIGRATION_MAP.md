# Карта объединения

## Из Labspirt V4042
- конечные автоматы `distillation_process`, `rectification_process`, `NBK_process`;
- стабилизация колонны и переходы «разгон → стабилизация → головы → тело → хвосты»;
- PI-регулирование мощности и коррекция по давлению;
- WaterControl, аварии, watchdog, DS18B20/1-Wire;
- локальный TFT ILI9341.

## Из HelloDistiller
- нумерация процессов 101–129;
- модель телеметрии (`FactPower`, температуры, давление, ШИМ, насос);
- конфигурационный `webui.json`;
- Wi-Fi, файловая система и браузерная панель;
- богатый набор режимов: термостат, ручная мощность, ректификация, НБК, пивоварня.

## Реализовано в v0.1
- независимые Model / Hardware / Controller / WebUi;
- безопасный старт с запрещённым силовым каскадом;
- процессы 102, 103, 104, 109, 112;
- аварии: потеря датчика, перегрев, давление, протечка;
- REST API и LittleFS;
- 16 MB partition table с двумя OTA-разделами и большим LittleFS.

## Нельзя считать завершённым
- коэффициенты MPX5010/GY-712 требуют стендовой калибровки;
- GPIO — предварительные, должны быть сверены с конкретной платой;
- фазоимпульсный симисторный регулятор пока заменён безопасным burst-fire для SSR;
- алгоритмы Labspirt перенесены концептуально, а не побитово;
- TFT, энкодер, рецепты, графики и OTA UI идут в следующую итерацию.
