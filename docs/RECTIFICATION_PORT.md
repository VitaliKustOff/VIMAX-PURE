# Перенос ректификации Labspirt → VIMAX.PURE ESP32-S3

## Соответствие контуров
- `Triac_Power_Val` / `PID_Power()` → PI-регулятор мощности ТЭНа по давлению.
- `OCR_PWM` / `Def_OSR()` → регулирование подачи воды в дефлегматор по температуре `Tdef`.
- `OCR_CEL` → импульсный процент открытия клапана отбора.

## Этапы
1. Разгон: ТЭН на заданной мощности, отбор закрыт.
2. Работа на себя: 1800 с, температура дефлегматора 74.00 °C.
3. Головы: температура дефлегматора 75.84 °C, отдельный процент отбора.
4. Тело: температура дефлегматора 74.00 °C; отбор линейно падает с 85% до 10% при росте температуры куба 86→92 °C.
5. Хвосты: отбор продукта закрыт, температура дефлегматора 77.00 °C.
6. Охлаждение и завершение.

## Отличия от исходника
- Все величины переведены в инженерные единицы, без STM32 HAL и значений таймерных регистров.
- Добавлены проверки датчиков, перегрева, давления и протечки.
- Автоматический переход из хвостов сделан по `tailsEndBoilerC`, поскольку в исходном фрагменте завершение хвостов выполнялось оператором.
- Назначение DS18B20 по индексам временное; для стенда требуется привязка по ROM-адресам.
