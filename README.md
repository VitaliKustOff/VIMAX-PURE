# VIMAX.PURE ESP32-S3 N16R8 v0.2 — Rectification Only

В этой версии исполнительная логика реализована только для процесса `109 — Ректификация`.
Все остальные процессы присутствуют как безопасные заглушки и никогда не активируют ТЭН или клапаны.

## Сборка
1. Установить VS Code и расширение PlatformIO.
2. Распаковать архив и открыть папку `VIMAX_PURE_ESP32S3` через **PlatformIO: Open Project**.
3. Подключить ESP32-S3 N16R8 по USB.
4. Выполнить `Upload Filesystem Image`, затем `Upload`.
5. Подключиться к Wi-Fi `VIMAX-PURE`, пароль `vimaxpure`, открыть `192.168.4.1`.

## Первый запуск
- Не подключать ТЭН и сетевое напряжение.
- Проверить датчики и GPIO светодиодами/лампой через развязанный драйвер.
- Силовой выход после загрузки запрещён и разрешается отдельно через веб-интерфейс.

## Необходимо адаптировать под плату
- GPIO в `include/BoardConfig.h`.
- ROM-адреса DS18B20 и их назначение.
- Калибровку датчика давления.
- Тип силового драйвера: zero-cross SSR или фазовый симисторный регулятор.
- Типы клапанов и допустимый период импульсного управления.

Подробная карта алгоритма: `docs/RECTIFICATION_PORT.md`.
